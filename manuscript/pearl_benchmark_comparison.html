Reading notes

  • All methods now have bootstrapped 95% CIs (10,000 resamples, normal-approximation) on every dataset — see the "Mean ± standard error, by dataset" section below for the whisker view. A close point-estimate "win" (e.g. a LoRA method edging past PC-only) should still be read against the whisker overlap there before treating it as statistically confirmed.
  • E2E LoRA columns show the best-performing loss variant (Focal / Weighted / Huber) and base model for that dataset; the sub-label under each method name names which one.
  • FT Embed and FT Embed+PC freeze the finetuned CLM as an embedding extractor and train a fresh XGBoost/LightGBM/CatBoost search on top — either the embedding alone, or embedding + the same 473-dim PC feature vector used by PC-only. Best of HF (6 sub-models × 2 losses) and Uni-Mol is shown (by Spearman for regression, MCC for classification), sub-labelled with the winner, and every entry now has a bootstrapped CI (including BACE/BBBP/CLINTOX/FLAVOR's pre-existing EffiChem_Extras results, computed by reloading the saved model and its exact test feature matrix). Uni-Mol never got an FT+PC variant for the original 4 datasets (HF only). FT Embed+PC trails PC-only almost everywhere — concatenating a 384–2560-dim frozen, mean-pooled embedding onto 473 PC features gives tree ensembles a much higher-dimensional, less sample-efficient search than PC-only's curated feature set, especially on the smaller datasets.
  • RAFE (Retrieval-Augmented Feature Extraction) concatenates [CLM embedding + PC features + 57 ZINC-250k retrieval features per model] — nearest-neighbor physicochemical stats (logP/QED/SAS, k=10/20), neighborhood density, a PCA-32 centroid, and Tanimoto structural similarity, retrieved via a GPU FAISS cosine index over all 249,455 ZINC-250k molecules. Best of HF and Uni-Mol is shown per dataset (by MCC/Spearman), same as FT Embed. RAFE now beats every other method on BBBP (MCC 0.798) and DILI (MCC 0.790, Uni-Mol) — the only two datasets where the extra retrieval context clearly helps; elsewhere it lands close to FT Embed+PC, consistent with retrieval features adding little once the model already has a strong embedding plus curated PC descriptors. BACE/BBBP/CLINTOX/FLAVOR's CI comes from a pre-existing EffiChem_Extras aggregate (bootstrap_ci_approx.json) rather than this session's reconstruct-and-rebootstrap method, because those RAFE runs' saved models and ZINC retrieval-feature CSVs were not retained on disk — the approx CI is normal-approximation SE from the same resampling family but was not independently re-verified this session, so treat old-dataset RAFE whiskers as slightly less certain than the rest. herg/dili/caco2/half_life's RAFE CI is the full 10,000-resample bootstrap on freshly reloaded models, same as everywhere else.
  • MolFormer's bundled remote code uses Performer-style random-feature attention; evaluation now forces deterministic_eval=true so results are reproducible run-to-run, matching the originally trained checkpoints' saved projection weights.
