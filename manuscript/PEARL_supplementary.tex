with RDKit~3.x and NetworkX~3.x.

\texttt{GetMorganGenerator}; MACCS keys use the standard 167-bit MACCS key
definition (\texttt{MACCSkeys.GenMACCSKeys}).

68 features found to be numerically unstable, redundant, or near-zero variance
on drug-like molecules (BCUT descriptors, partial-charge extrema, $\chi$-series,

\paragraph{Zero-shot evaluation.}
Zero-shot performance of CLMs on molecular property prediction tasks is generally
poor for binary/multi-class classification because the models were pretrained to reconstruct SMILES tokens (masked-language modelling) or predict molecular properties via regression (multi-task regression), not to output class labels. Without finetuning, CLM representations encode general molecular structure but lack task-specific discriminative features.
Empirically, zero-shot linear probes on ClinTox and BACE achieve MCC~$< 0.1$ for
ChemBERTa models not specifically pre-trained on toxicity data, confirming that task alignment is essential.

\paragraph{Full finetuning vs.\ LoRA.}
Full finetuning updates all model parameters for the downstream task, maximizing task-specific adaptation but incurring high memory cost ($\mathcal{O}(|\theta|)$ gradient storage) and risking catastrophic forgetting of pre-trained chemical knowledge.

Low-Rank Adaptation (LoRA) decomposes the weight update $\Delta W \in \mathbb{R}^{d \times k}$
as the product $BA$ where $B \in \mathbb{R}^{d \times r}$, $A \in \mathbb{R}^{r \times k}$
with $r \ll \min(d, k)$, reducing trainable parameters by $76-97\%$ without degrading
predictive accuracy.
Across all four PEARL datasets, LoRA-finetuned models match or exceed full finetuning
benchmarks reported in prior work (MolFormer WL BBBP MCC~$= 0.797$; Uni-Mol WL BACE
MCC~$= 0.623$), confirming that the task-relevant weight update lives in a low-rank
subspace.

\paragraph{Comparison to reported baselines.}
MolFormer-XL full finetuning on BBBP achieves MCC~$\approx 0.79$ in the original paper~\cite{ross2022molformer}, matching our LoRA results (MCC~$= 0.797$) while using
only $6-9\%$ of parameters.
ChemBERTa-2 full finetuning on ClinTox achieves AUROC~$= 0.97$-$0.99$ in the
original benchmark~\cite{ahmad2022chemberta2}; our LoRA MolFormer FL achieves
AUROC~$= 0.993$ with $3.44\%$ trainable parameters.

\phantomsection\addcontentsline{toc}{subsection}{Section S2: LoRA for Uni-Mol - Mathematical Formulation and Implementation Details}
\subsection*{Section S2: LoRA for Uni-Mol - Mathematical Formulation and
Implementation Details}
%% -----------------------------------------------------------------------------

\paragraph{Architecture background.}
Uni-Mol~\cite{zhou2023unimol} is a SE(3)-equivariant Transformer operating on
3D atomic coordinate inputs.
Each attention layer computes
$\text{Attn}(Q, K, V) = \text{softmax}\!\left(\tfrac{QK^\top}{\sqrt{d_k}}\right)V$
where the projection matrices $W_Q, W_K, W_V, W_O \in \mathbb{R}^{d \times d}$
are merged into a single \texttt{in\_proj} weight matrix of shape
$\mathbb{R}^{3d \times d}$ in the PyTorch implementation
(where $d = 512$ for the base Uni-Mol model).

\paragraph{LoRA targeting.}
For Uni-Mol, LoRA adapters are applied exclusively to the \texttt{in\_proj} weight
matrices of all self-attention layers.
Each adapter decomposes $\Delta W_{\texttt{in\_proj}} \approx B\,A$ with
$B \in \mathbb{R}^{3d \times r}$, $A \in \mathbb{R}^{r \times d}$, scaling by
$\alpha / r$ at inference.
This targeting is preferred over query-only or query+value targeting because
the merged \texttt{in\_proj} encodes $Q$, $K$, and $V$ projections jointly;
adapting only part of it creates gradient flow asymmetries that degrade convergence.

\paragraph{Gradient flow preservation.}
SE(3)-equivariant message passing in Uni-Mol depends on pair distances computed
from explicit 3D coordinates.
To preserve equivariance, only the attention projection weights are adapted;
distance-based pair encodings ($\boldsymbol{\phi}(\|r_i - r_j\|)$) are kept frozen.
The gradient from the downstream classification loss flows through the LoRA adapter
and into the conformer features, providing indirect adaptation of the 3D representation.

\paragraph{Conformer caching.}
Uni-Mol requires 3D conformers generated by ETKDGv3~+ MMFF94 relaxation (RDKit).
Conformer generation is computationally expensive ($\sim$0.5~s per molecule for
flexible drug-like compounds).
To avoid redundant computation across training epochs and evaluation splits,
conformers are pre-generated once and stored as
\texttt{.pkl} archives keyed by canonical SMILES.
During training, the data loader reads cached conformers; cache misses fall back
to on-the-fly generation.

\phantomsection\addcontentsline{toc}{subsection}{Section S3: PEARL Custom Trainer - Loss Functions, Class Weights, and Evaluation}
\subsection*{Section S3: PEARL Custom Trainer - Loss Functions, Class Weights,
and Evaluation}
%% -----------------------------------------------------------------------------

\paragraph{Loss functions.}
PEARL implements two loss functions selectable per run:

\begin{itemize}[leftmargin=2em]
\item \textbf{Focal Loss (FL).}
  $\mathcal{L}_\text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log p_t$
  with $\gamma = 2$ and $\alpha_t$ set by class frequency.
  The $(1 - p_t)^\gamma$ modulating factor down-weights easy examples and focuses
  training on hard, misclassified samples.
  FL is particularly effective for tasks with challenging
  examples (e.g., ClinTox classification).

\item \textbf{Weighted Cross-Entropy (WL).}
  $\mathcal{L}_\text{WL} = -\sum_c w_c \log p_c$
  with class weight $w_c = N / (C \cdot n_c)$, where $N$ is total training samples,
  $C$ is the number of classes, and $n_c$ is the count for class $c$.
  Weighting the loss by inverse class frequency is preferred for severe imbalance
  (BBBP and Flavor multi-class) where FL's hard-example focus is less critical
  than correcting the class prior.
\end{itemize}

\paragraph{Class weight computation.}
For binary tasks, scale\_pos\_weight = $n_\text{neg} / n_\text{pos}$ is passed to
tree-based classifiers (XGBoost, LightGBM, CatBoost) during ML-stage training,
matching the class imbalance correction applied during CLM finetuning.
This ensures end-to-end consistency: the CLM embedding was tuned with the same
class prior correction as the downstream tree classifier.

\paragraph{Evaluation metrics.}
All results report:
\begin{itemize}[leftmargin=2em]
  \item \textbf{MCC} (Matthews Correlation Coefficient): primary ranking metric,
    robust to class imbalance.
  \item \textbf{AUC}: area under the ROC curve; macro one-vs-rest for multi-class.
  \item \textbf{F1$_\text{mac}$} / \textbf{F1$_\text{mic}$}: macro-/micro-averaged F1.
  \item \textbf{Accuracy, Precision$_\text{mac}$, Recall$_\text{mac}$}:
    macro-averaged precision and recall.
\end{itemize}
All metrics are computed on a held-out test set unseen during training and
hyperparameter optimization.
Optuna (20 trials, TPE sampler) is used for ML-stage hyperparameter search.

\subsection*{Section S4: RAFE Pipeline Details}

\paragraph{ZINC-250k preparation.}
ZINC-250k~\cite{gomez2018automatic} contains 249{,}455 drug-like molecules.
The raw dataset is cleaned by: (i)~removing molecules that cannot be parsed by
RDKit; (ii)~standardising SMILES with RDKit MolStandardise; (iii)~computing
LogP, QED, and SAS (Synthetic Accessibility Score) for each molecule.
The cleaned library is embedded using each task-specific finetuned model
(ChemBERTa, MolFormer, or Uni-Mol with LoRA weights) and normalized to unit $\ell_2$ norm.

\paragraph{FAISS index construction.}
For each (dataset, CLM variant, loss) combination, a separate FAISS
\texttt{IndexFlatIP} (exact inner-product, equivalent to cosine similarity for
$\ell_2$-normalised vectors) is built over the ZINC-250k embeddings.
For large embedding dimensions (Uni-Mol: 2560~dim), HNSW (\texttt{IndexHNSWFlat})
with $M = 32$, $\texttt{efSearch} = 64$ is also evaluated; FlatIP is preferred
for accuracy-critical tasks (BACE), while HNSW provides a $3$-$5\times$ speedup
with $< 0.5\%$ recall drop for retrieval tasks.
FAISS indices are built once and stored as \texttt{.index} files to avoid redundant
re-embedding of ZINC-250k.

\paragraph{PCA fitting strategy.}
The 69-dimensional RAFE vector includes a 32-dimensional PCA-compressed centroid of the $k=10$ nearest ZINC-250k neighbours in embedding space.
PCA is fitted on the \emph{training} split only and applied without re-fitting to the validation and test splits, preventing any data leakage from retrieval.

\subsection*{Method Descriptions}

\noindent\textbf{Chemprop / D-MPNN}~\cite{yang2019chemprop}.
Directed Message Passing Neural Network with a learned bond-message-passing scheme.
Regarded as a strong GNN baseline for MoleculeNet tasks; trained end-to-end on
molecular graphs without pretraining.

\noindent\textbf{GROVER}~\cite{rong2020grover}.
Self-supervised graph transformer pretrained on 10M unlabelled molecules using
node/edge-level and graph-level self-supervised objectives, then finetuned on
downstream tasks. GROVER-Large uses a 48-layer, 3.4M-parameter encoder.

\noindent\textbf{AttentiveFP}~\cite{xiong2020attentivefp}.
Graph neural network with attention-based message passing specifically designed
for molecular property prediction. Uses atomic and bond features with multi-hop
neighbourhood aggregation.

\noindent\textbf{Mole-BERT}~\cite{xia2023molecbert}.
Pretrained GNN that replaces atom tokens with a vocabulary of 2{,}000 atom-context
tokens learned via $k$-means clustering on extended connectivity features,
enabling BERT-style pretraining on molecular graphs without SMILES.

\noindent\textbf{Uni-Mol (original)}~\cite{zhou2023unimol}.
SE(3)-equivariant 3D Transformer pretrained on 209M molecular conformers.
Full finetuning on downstream tasks (as reported in the original paper),
not LoRA; provided as a reference upper bound for the Uni-Mol architecture family.

\noindent\textbf{MolFormer (full FT)}~\cite{ross2022molformer}.
MolFormer-XL with full parameter finetuning on each downstream task, as reported in the
original paper. Included to show that PEARL LoRA matches full finetuning while using
only 3--16\% of parameters.

\noindent\textbf{FART (Zimmermann et al.)}~\cite{zimmermann2024fart}.
The language model introduced with the Flavor dataset. Included for comparison
on the five-class Flavor task only; no MoleculeNet results are available.

\subsection*{Key Observations}

\paragraph{BACE:}
PEARL Uni-Mol WL achieves AUC~$= 0.891$, competitive with GROVER-Large
($0.894 \pm 0.028$), an overlap within the reported standard deviation, while
using only $\sim\!4.5\%$ of trainable parameters relative to full finetuning.
Uni-Mol LoRA (AUC~$= 0.891$, MCC~$= 0.623$) outperforms the published Uni-Mol
full-finetuning result (AUC~$= 0.857$)~\cite{zhou2023unimol}, confirming that LoRA
adaptation provides a beneficial regularisation effect on this small dataset
(1{,}513 molecules). Chemprop and AttentiveFP (AUC $\leq 0.861$) are substantially
below PEARL, consistent with the hypothesis that 3D geometric inductive biases
confer an advantage on binding-affinity tasks.

\paragraph{BBBP:}
PEARL MolFormer WL (E2E LoRA, AUC~$= 0.948$) exceeds GROVER-Large
($0.940 \pm 0.016$) and Mole-BERT ($0.940 \pm 0.011$), and matches the best
RAFE configuration (AUC~$= 0.940$, MCC~$= 0.798$). MolFormer full finetuning
achieves AUC~$= 0.932$~\cite{ross2022molformer}; PEARL LoRA not only matches but
surpasses this with $6$--$9\%$ of parameters, demonstrating that the task-relevant
adaptation subspace is intrinsically low-rank for this dataset.
AttentiveFP's unusually low BBBP AUC ($0.646 \pm 0.052$) likely reflects a
different scaffold-split proportion used in their evaluation~\cite{xiong2020attentivefp}.

\paragraph{Flavor:}
Zimmermann et al.~\cite{zimmermann2024fart} report accuracy, macro-F1, and AUROC
($= 0.964$) for their chemical language model but do not compute MCC, precluding
direct numerical comparison on that metric.
On AUC, PEARL MolFormer WL (E2E LoRA, AUC~$= 0.975$) and Uni-Mol WL
(E2E LoRA, AUC~$= 0.973$) exceed Zimmermann et al.'s AUROC of $0.964$ by
$+0.011$ and $+0.009$, respectively (see Table~\ref{tab:s5_external}).
This AUC improvement is achieved with LoRA fine-tuning using only $3$-$4\%$ of
model parameters.
On MCC, PEARL MolFormer WL (E2E LoRA, MCC~$= 0.801$, 95\,\% CI $[0.782, 0.820]$;
RAFE MCC~$= 0.804$, 95\,\% CI $[0.784, 0.824]$) provides the current reference
result on this benchmark.
